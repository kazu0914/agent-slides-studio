# 動くフロー図

編集タブの「要素を追加」から「工程フローを追加」「分岐フローを追加」を選びます。図の中の箱・説明・アイコン・接続先・順番は、選択後の「フローの編集」で変更できます。スライド上では図全体を移動・拡大縮小できます。ひな型は見出し・本文・既存要素を避けて配置します。読める大きさを保つ空き領域がなければ追加せず、メッセージを表示します。数値欄はEnterまたは欄の外をクリックして確定し、Escで入力を取り消します。

## AIに作ってもらう

「AIにフローを依頼」またはエージェントタブの「動くフロー図を依頼する」で依頼文を呼び出し、内容を変えて送信します。たとえば「問い合わせを分類し、営業・サポート・その他に分岐する図」「入力から検索、回答まで順番に伝わる図」など。Codexが現在のデッキを読み取り、箱の配置と接続を含む変更案を返します。「変更前／採用後」を比較してから適用してください。

Claude Codeなどから作る場合は「エージェント連携」→「現在の内容を渡す」で、現在のデッキとフロー仕様・例を含むJSONを保存します。外部エージェントにそのファイルと依頼を渡し、返された変更案JSONをStudioに貼り付けて比較・適用します。変更案には、渡したデータの `baseDeckId` と `baseVersion` をそのまま含めます。古い版・別のデッキ・生成元情報のない案は拒否されるため、最新の内容を渡して再生成してください。版番号だけを書き換えて古い案を使い回さないでください。この手順はファイルによる受け渡しです。Claude CodeをStudioから直接起動する機能はありません。

## 再生

「演出をプレビュー」または「プレゼンテーション」で動きを確認します。編集キャンバスは図全体が見える静止状態です。

- 信号が流れる：線に沿って点が移動します。
- 線が伸びる：接続線が順番に描かれます。
- 工程を順に強調：到着した箱が明るくなります。

同じ順番の接続は同時に流れ、後の番号の接続は次に流れます。秒数は一巡の長さです。繰り返しを外すと一度再生して完成状態を保持します。プレゼンのPキーで一時停止・再開できます。OSの「視差効果を減らす」に従い静止表示になります。

PDF・PowerPointには全ての箱と接続を静止状態で出力します。PowerPoint内のフロー部分は画像です。動きや箱単位の編集はStudioで扱います。

## 確認した範囲（2026-10-12）

型検査・ビルド・既存単体テスト、グラフのID／接続先／座標検証、分岐と順次の時間計算、ブラウザーでの挿入・編集・保存・再読込、信号移動、停止再開、動作軽減設定、PDF/PPTX出力、外部エージェント用JSONの書き出しとレビュー適用を確認。既存デッキを変更せずにローカルサーバーを更新しています。

実際のCodex接続でも、短い依頼文から分岐図が生成され、1件の要素追加として比較・適用・保存できることを確認しました。完成サンプルは「動くフロー図｜分岐と工程」（2枚）。1枚目はCodex生成、2枚目は工程フローのひな型です。Claude Code自身の生成実行は今回未実施で、ファイル受け渡し仕様とJSON適用経路を検証しています。
