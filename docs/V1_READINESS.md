# v1.0.0の公開基準（提案）

最初の正式版はmacOS向けのローカルアプリとして範囲を明示する。
機能数ではなく、既存機能が継続して安全に使えることを公開基準にする。
以下は公開前に確認すべき項目であり、全項目が検証済みという意味ではない。

1. 保存と復旧：連続編集、スライド移動、保存中の終了、通信失敗、複数タブ競合を再現し、変更を失わず復旧できる。アプリ更新前後のデータ移行とバックアップ復元も確認する。
2. 初回導入：開発者以外のMacでREADMEだけを使って導入できる。Codexなしでも手動編集でき、ログイン・利用上限・起動失敗の対処が分かる。
3. 回帰テスト：追加、編集、複製、ドラッグ、回転、削除、Undo/Redo、自動保存、プレゼン、PDF/PPTX出力をCIで検証する。現在の手動・ローカル検証を配布対象の自動テストへ移す。
4. セキュリティと互換性：既知の依存パッケージ警告を再評価し、更新・代替・到達経路の検証で対処を確定する。SVG/PPTX/JSON入力、ファイル容量制限、秘密情報除外を確認する。PPTX変換の非対応項目、自作SVGの再生制御の制限を明示する。
5. リリース手順：初回ガイド、練習用サンプル、変更履歴、既知の制限、Issue受付、バージョン表示、更新・バックアップ手順を整え、クリーンな配布物にv1.0.0タグを付ける。

追加のモーション、完全なPowerPoint互換、SaaS課金、共同編集、動画出力は正式版の前提にしない。
Windows/Linuxは実機確認が済むまで未検証と明記する。まずv0.9ベータで外部の少人数に実際の資料作成を試してもらい、保存・起動・編集の重大な問題を解消してからv1.0.0とする。
