# 5分で試す

## 起動する

READMEの手順でインストールし、`npm start` 後に http://127.0.0.1:9182 を開きます。
Node.js 22.13以上、npmが必要です。最初の対象OSはmacOSです。

1. マイスライドで「練習用サンプルをダウンロード」を押します。
2. 「JSONから取り込む」でダウンロードした `getting-started.json` を選びます。
3. 「編集」タブでタイトルを書き換えます。約1秒後に自動保存されます。
4. 「ログ」で変更前後を確認します。
5. 「プレゼンテーション」を開き、矢印キーで進みます。Escで終了します。

PowerPointから試す場合は「PowerPointを取り込む」で `.pptx` を選んでください。
取り込んだ文字は「編集」タブでダブルクリックし、画像や図形はドラッグできます。
未対応要素はREADMEの互換性説明と取り込み結果を確認してください。

## 自分のCodexをつなぐ

Codex CLIをインストールし、ターミナルで `codex login` を実行します。
アプリの「再確認」を押し、接続済みになったら指示を送ります。
複数枚を作るときは変更範囲を「デッキ全体」にしてください。
変更案を比較して採用するとスライドに反映されます。
Web検索は未対応です。資料本文を指示に添えてください。
APIキー認証の場合はAPIの従量料金が発生します。

## データを守る

- アプリを閉じる前に「保存済み」の表示を確認します。
- 「バックアップ」は画像・変更履歴・AI会話を含みます。公開しないでください。
- 別環境では「履歴込みバックアップから復元」を使います。
- 削除したデッキは「ゴミ箱」から復元できます。
- アプリの更新時は `.local-data` を保持してください。先にバックアップすることを勧めます。

## 困ったとき

| 症状 | 確認すること |
| --- | --- |
| Codexが見つからない | CLIのインストール、PATHまたはFRAME_CODEX_BIN |
| 未ログイン | codex login後に「再確認」 |
| 利用上限 | 回復を待って「再確認」。手動編集は利用可能 |
| 接続できない | CLIの版、ログイン、ネット接続。設定後に再確認 |
| PDF/PPTXが出ない | Chromeまたは `npx playwright install chromium` |
| ポートが使用中 | 既存の起動を確認。必要ならFRAME_PORTを変更 |

不具合はOS・Node/Codexのバージョン・手順とともに報告してください。
サンプルで再現できる場合は、個人資料の代わりにサンプルを使ってください。
