# 公開前セキュリティ確認（2026-09-14）

対象は配布用のローカル版です。旧Sites版や公開Webサービスとしての運用は対象外です。

## 修正

- CSPとX-Frame-Optionsで外部サイトへの埋め込みを禁止し、外部スクリプト・プラグインを禁止。
- Host/Origin検証に加え、cross-siteのFetch Metadata要求を拒否。
- HTTP本文をバイト列として上限付きで蓄積し、結合後にUTF-8へ変換。日本語の途中で通信が分割された場合の文字化けを修正。
- PPTXのグループ再帰を32階層に制限。既存の圧縮ファイル・展開サイズ・XML・スライド数の制限も維持。

## 確認した境界

- サーバーは127.0.0.1だけで待ち受ける。アプリ認証はなく、同じMac上の別プロセスに対する隔離はない。
- SQLへの利用者入力はバインド値として扱う。保存は版番号と一意制約で競合を検出。
- 画像パスはローカルの所定形式のみ。任意の外部URLやファイルパスは受け付けない。
- Reactは文字列をエスケープ。自作SVGはHTMLへ直接挿入せず画像として表示する。
- Codex接続はシェル文字列経由ではなくspawnの引数配列を使用。read-only、shell無効、追加ツール要求拒否。実際の隔離保証は利用者のCodex実装にも依存する。
- 公開用ファイルスキャンで秘密鍵・トークン形式・個人データ・非公開背景を検査。網羅的な秘密情報検出の保証ではない。

## 残る依存ライブラリ警告

npm auditはCritical 0、High 2パッケージを報告する（image-sizeと、その親pptxgenjs）。
image-size 2.0.2のICNS/JXL/HEIFパーサーに処理停止の既知問題があり、調査時点で修正版はない。
本アプリはPptxGenJSの全画像挿入箇所にブラウザ生成PNGだけを渡すため、問題の形式へ利用者入力が直接到達する経路は確認していない。
これは到達性の制限であり、依存関係から脆弱性を取り除いたことにはならない。

## 検証範囲と限界

型検査・単体テスト・ビルドに加え、隔離したテストデータでHost/Origin/Fetch Metadata拒否、分割UTF-8受信、入力中の保存抑止、保存失敗からの再試行、競合、再読み込み、バックアップ復元、公開背景、PDF/PPTX出力を確認する。
独立した侵入テストや網羅的なファジングではない。既知警告を開示したローカル専用ベータとして扱い、インターネットへポートを公開しない。
