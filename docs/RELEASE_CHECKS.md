# v0.9.0-beta.1 の確認範囲

2026-09-14 / macOS。以下はこの候補版の確認記録です。

- 個人データを除いた最小依存構成から npm ci / typecheck / test / build / check:release
- 初回起動、非公開背景6枚なし、Codex未インストール時の案内と手動編集
- サンプルJSONのダウンロード・取り込み・直接編集・コメントなしの自動保存
- 保存後のサーバー再起動と保持、削除したデッキのゴミ箱からの復元
- 空の保存先へのバックアップ復元（画像・本文・履歴・会話）
- 実ブラウザでPDF/PPTX書き出しとプレゼン開始/終了
- 自動保存の通信失敗・再試行、保存直後のプレゼン開始、古い版からの上書き拒否
- 認証なし・上限到達・APIキー・取得失敗の分類、PPTX取り込みの順序/配置/不正XML拒否

`npm run build && npm run test:e2e` で実ブラウザによる主要フローを再検証できます。
ChromeまたはPlaywright Chromiumが必要です。テストは9192番ポートと一時ディレクトリを使います。
個人の `.local-data` は使いません。9192番ポートで他のサービスが起動していないことを確認してください。

- 作者のCodex認証で、公開サンプルのタイトル変更提案・編集範囲の保持・適用を実行

## 限界

Windows/Linuxの実機、他人のChatGPTアカウント、全種類のPowerPoint、長期運用、
低メモリ環境での性能は検証していません。NodeのCIは実機のUI確認を代替しません。
画像パーサー依存関係の既知の警告は SECURITY.md に記載しています。
この版は個人のMacで試す無料ベータ版で、公開Webサービス用ではありません。
